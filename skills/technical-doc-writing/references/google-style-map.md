# Google style guide: local chapter map

Use this map to choose **only the chapters relevant to the document**. Paths below are relative to this file in `references/` and point to the downloaded official Markdown in `google-style-guide/`. The [full index](google-style-guide/README.md) contains every chapter and its `.md.txt` source URL. Project-specific guidance takes precedence; the [guide's philosophy](google-style-guide/philosophy.md) describes these as Google house-style choices.

## Start with the document's purpose

- [About this guide](google-style-guide/index.md) and [highlights](google-style-guide/highlights.md): scope and the main editorial choices.
- [Prescriptive documentation](google-style-guide/prescriptive-documentation.md): recommend a path for common tasks and make requirements, options, and outcomes precise.
- [Headings and titles](google-style-guide/headings.md), [paragraph structure](google-style-guide/paragraph-structure.md), and [sentence structure](google-style-guide/sentence-structure.md): organize for scanning, put the key point first, and place conditions before instructions.
- [Procedures](google-style-guide/procedures.md): ordered, actionable steps; introductions and optional steps.
- [Lists](google-style-guide/lists.md) and [tables](google-style-guide/tables.md): choose a format that matches the relationships among items.
- [Cross-references and linking](google-style-guide/cross-references.md): provide essential context in place and write descriptive links.

## Choose the document type

- **Tutorial or how-to:** [procedures](google-style-guide/procedures.md), [code samples](google-style-guide/code-samples.md), [placeholders](google-style-guide/placeholders.md), and, for shell tasks, [command-line syntax](google-style-guide/code-syntax.md).
- **Conceptual explanation:** [paragraph structure](google-style-guide/paragraph-structure.md), [headings](google-style-guide/headings.md), [jargon](google-style-guide/jargon.md), and [figures](google-style-guide/images.md) if a visual explanation is useful.
- **API reference:** [API reference code comments](google-style-guide/api-reference-comments.md), [verbs in reference documentation](google-style-guide/reference-verbs.md), [code in text](google-style-guide/code-in-text.md), and [code samples](google-style-guide/code-samples.md).
- **CLI reference or command example:** [command-line syntax](google-style-guide/code-syntax.md), [placeholders](google-style-guide/placeholders.md), and [code in text](google-style-guide/code-in-text.md).
- **UI instructions:** [UI elements and interaction](google-style-guide/ui-elements.md), [procedures](google-style-guide/procedures.md), and [accessibility](google-style-guide/accessibility.md).
